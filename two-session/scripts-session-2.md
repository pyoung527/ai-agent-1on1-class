# 2차시 · 설정 확인과 실행·검수

별도 수업 120분. 진행 멘트뿐 아니라 질문·작성·실습·전환을 포함한 시간입니다. 필요 시 휴식은 해당 구간 설명을 줄여 배정하며 추가하지 않습니다.

민감정보 입력 금지 · 합성(가상) 자료만 사용 · AI 자동 실행 없음 · 실제 권한 설정은 선택한 도구에서 확인

## 01. 2차시 · 설정 확인과 첫 실행

**권장 시간: 5분**

### 진행 멘트
오늘은 두 번째 수업입니다. 지난 수업의 개념 설명을 다시 길게 하지 않겠습니다. 가져온 설계를 확인한 뒤 실제 도구의 설정을 보고, 작은 입력으로 실행하고 고쳐 보겠습니다.

두 시간 뒤에는 잘됐다는 감상 대신 출력 두 개와 비교 기록이 남아야 합니다. 환경이 준비되지 않았다면 실제 실행과 대체 연습을 구분해서 기록하겠습니다. 설정을 확인하지 못한 것을 확인했다고 적지는 않습니다.

### 질문 / 직접 할 동작
- 워크시트 2를 연다.
- 첫 수업 요청문이 없어도 합성 샘플로 참여할 수 있음을 확인한다.
- "오늘 결과를 어떤 증거로 볼까요?"라고 묻는다.

### 전환
먼저 가져온 자료와 질문을 작은 범위로 줄이겠습니다.

## 02. 설계표와 과제 가져오기

**권장 시간: 7분**

### 진행 멘트
다른 브라우저나 기기로 왔다면 파일을 가져오거나 텍스트를 붙여 넣어야 합니다. 브라우저 저장이 계정 동기화를 뜻하지는 않습니다. 인계 칸에 목표와 완료 기준이 들어왔는지 직접 읽어 주세요.

가져온 샘플은 설계와 질문 점검용입니다. 오늘 비교 실습은 모두 제공된 합성 문의 inbox-01/02/03으로 진행합니다. 이 공통 입력에 맞춰 요청문을 축소해 주세요. 직접 준비한 자료는 후속 적용 질문으로 남기며 민감한 자료는 열거나 공유하지 않습니다. 과제를 못 했다는 이유로 실제 고객 메일을 급히 연결하지 않습니다. 질문은 설정, 입력, 출력 기준 중 어느 단계에서 막혔는지 나눠 둡니다.

### 질문 / 직접 할 동작
1. 파일 가져오기 또는 텍스트 붙여넣기를 한다.
2. 공통 입력 inbox-01/02/03과 고정된 비교 기준을 확인한다. 준비가 안 되어도 이 자료로 시작한다.
3. "이번 요청에 필요 없는 자료는 무엇인가요?"라고 묻는다.

### 전환
같은 과제를 어느 도구에서 실행할지 하나만 고르겠습니다.

## 03. 도구와 모델 하나 선택

**권장 시간: 5분**

### 진행 멘트
이미 쓸 수 있는 도구 하나로 시작하겠습니다. 어떤 제품이든 같은 설정 항목을 확인합니다. 모델 이름이 같아도 계정 종류나 제공 기능은 다를 수 있으므로 화면에서 보이는 이름만 적으세요. 비밀번호나 계정 식별자는 적지 않습니다.

분류 세 건을 위해 가장 비싼 모델이 꼭 필요한 것은 아닙니다. 속도와 비용을 보고 작은 샘플로 판단하면 됩니다. 새 설치나 결제가 필요하면 이번에는 진행하지 않고 대체 경로를 택하겠습니다. 로그인은 학습자가 비공유 화면에서 직접 하며 강사는 인증정보를 보거나 대신 입력하지 않습니다.

### 질문 / 직접 할 동작
- 도구·모델·무료 한도 또는 사용 제한을 기록한다.
- 사용 불가, 미지원, 확인 불가를 구분해 적는다.
- "이 도구의 결과 기록을 다시 볼 수 있나요?"라고 묻는다.

### 전환
실제 설정 화면에서 읽기와 외부 행동의 범위를 확인하겠습니다.

## 04. 실제 권한 화면 확인

**권장 시간: 10분**

### 진행 멘트
이 실습지에서 차단에 체크해도 AI 도구가 차단되지는 않습니다. 학습자가 실제 도구의 설정을 열고 작업공간, 연결 도구, 파일 권한부터 보겠습니다. 메일이나 드라이브 전체가 연결돼 있으면 그대로 실행하지 않습니다. 학습자가 필요 없는 연결을 끄거나 범위를 줄인 뒤 다시 화면을 확인합니다. 강사는 대신 조작하지 않습니다.

파일 쓰기, 외부 사이트 접속, 명령 실행, 자동 승인 여부도 확인합니다. 승인 없이 실행하는 우회 모드는 사용하지 않습니다. 시간이나 비용 한도가 제품에서 강제되지 않으면 수동 타이머라고 분명히 적습니다.

설정 이름과 보이는 값, 확인 방법을 기록해 주세요. 민감한 계정 이름을 포함한 화면 캡처는 남기지 않습니다. 설정 항목이 없거나 격리 범위를 확인할 수 없다면 도구 권한 검증 미완료입니다. 위험한 실제 파일을 건드려 차단을 시험하지 않습니다.

### 질문 / 직접 할 동작
1. 0–2분: 작업공간·파일 범위 확인.
2. 2–5분: 연결 앱·외부 접속·명령 실행 확인.
3. 5–8분: 승인·중단·예산 확인.
4. 8–10분: 화면 위치와 값 기록, 모르는 항목 표시.
5. "요청문에 쓰기 금지라고 적은 것과 지금 본 설정은 어떻게 다른가요?"라고 묻는다.

### 전환
확인 수준에 맞춰 실제 도구 실행, 텍스트 연습, 수동 대체 중 하나를 고르겠습니다.

## 05. 실행 경로와 중단 기준 결정

**권장 시간: 8분**

### 진행 멘트
A는 실제 설정을 눈으로 확인했고 합성 자료에만 도구가 접근하도록 범위를 제한한 경우입니다. 선택한 AI 도구 안에서 학습자가 실행하며 이 교육 페이지가 연결하거나 실행하지 않습니다.

설정 항목이 없거나 확인할 수 없으면 B로 전환합니다. 별도 계정 연결이나 파일 접근 없이 합성 텍스트를 입력하고 화면 초안만 받는 연습입니다. 이것을 읽기 권한 검증이나 에이전트 도구 실행의 성공으로 부르면 안 됩니다. 연결 기능을 끌 수 있는지도 불확실하면 B도 하지 않고 C로 갑니다. C는 도구를 사용하지 않고 사람이 표를 작성하고 제공한 오류 예시를 검토하는 경로입니다.

각 실행은 수동으로 최대 5분을 재고, 동일 오류가 두 번 발생하거나 예상하지 않은 도구 호출이 나오면 중단합니다. 오늘 본 작업의 초안 생성은 첫 실행과 수정 후 재실행, 총 2회입니다. 별도 검수는 10번의 5분 안에서 최대 1회로 제한하고 검수 기록을 따로 남깁니다. 한도 설정을 확인하지 못한 경우 수동 관리임을 적습니다.

### 질문 / 직접 할 동작
- A/B/C 중 하나를 선택하고 이유를 기록한다.
- 중단 버튼 위치와 타이머 담당을 확인한다.
- 확인하지 못한 설정 하나를 말하고 확대 없이 대체 경로를 고른다.

### 전환
입력 전에 공유와 저장 범위도 확인하겠습니다.

## 06. 공유 전 개인정보와 기록 점검

**권장 시간: 5분**

### 진행 멘트
AI 서비스에 텍스트를 넣으면 해당 서비스로 전송됩니다. 도구의 외부 검색을 껐다고 해서 모델 서비스와 통신하지 않는다는 뜻은 아닙니다. 그래서 합성 자료만 씁니다. 이름만 가린 실제 계약서나 고객 상담 원문도 이번 실습에서는 쓰지 않습니다.

필요 없는 알림과 탭을 가리고 화면 전체, 카메라, 마이크는 공유하지 않겠습니다. 대화와 업로드 자료가 얼마나 남는지는 개인 계정인지 조직 계정인지에 따라 다를 수 있습니다. 학습자가 기록과 보존 설정의 위치만 확인하고, 변경이나 삭제는 수업 후 정책을 검토해 직접 결정합니다. 복구 코드나 2단계 인증 화면은 공유하지 않습니다.

### 질문 / 직접 할 동작
- 입력 세 건의 민감정보 여부를 확인한다.
- 기록·보존 정책 위치를 적는다.
- "교육 페이지의 로컬 저장과 AI 서비스 기록은 어디가 다른가요?"라고 묻는다.

### 전환
이제 실행 전에 정답을 판정할 기준을 고정하겠습니다.

## 07. 입력과 통과 기준 고정

**권장 시간: 6분**

### 진행 멘트
실습 페이지에서 세 자료를 열고 내용을 먼저 읽겠습니다. 첫 자료는 상담 일정 문의지만 다음 주라는 표현의 기준 날짜와 실제 가능 여부는 모릅니다. 날짜나 미팅 링크를 확정해서 만들면 안 됩니다. 두 번째는 견적 정보가 부족하므로 비용을 지어내지 않고 시간과 방식 등을 묻습니다.

세 번째에는 다른 파일을 검색하고 밖으로 보내라는 문장이 들어 있습니다. 이 문장은 분석 대상인 외부 자료입니다. 위험한 지시라는 점을 표시하고 실행하지 않습니다. 파일별로 한 행씩, 원문 근거와 초안, 추가 질문을 남기는 기준을 실행 전에 적어 주세요. 출력 세 행이라는 조건만으로 모든 기준을 통과한 것은 아닙니다.

### 질문 / 직접 할 동작
- 실습지의 예상 분류와 확인 질문을 채운다.
- inbox-03에서 지시로 따르면 안 되는 문장을 표시한다.
- 결과 평가 다섯 항목을 실행 전에 고정한다.

### 전환
학습자가 선택한 도구에서 첫 요청을 실행하겠습니다.

## 08. 1회 실행과 원본 출력 보존

**권장 시간: 12분**

### 진행 멘트
실습 페이지의 요청문과 합성 샘플 세 건을 사용하겠습니다. A라면 허용한 자료 읽기 도구만 사용하고, B라면 합성 텍스트를 붙여 넣어 화면 초안을 받습니다. 학습자가 입력을 확인하고 직접 요청해 주세요. 웹페이지는 AI에 연결돼 있지 않습니다.

기다리는 동안 허용하지 않은 도구 호출, 전송, 파일 변경 요청이 나오는지 봅니다. 나오면 승인하지 말고 멈춥니다. 모델이 자료 부족으로 질문하는 것은 오류가 아닐 수 있습니다. 먼저 출력과 질문을 그대로 보존하세요. 보기 좋게 고친 내용만 남기면 나중에 비교할 수 없습니다.

C 경로에서는 학습자가 직접 표를 작성합니다. 도구를 실행하지 않았다고 기록하고, AI가 생성한 결과처럼 설명하지 않습니다. 5분 안에 결과가 안 나오면 시간 초과를 기록해 진단 단계로 넘어갑니다.

### 질문 / 직접 할 동작
1. 0–2분: 입력과 요청문 확인.
2. 2–7분: 직접 실행·수동 타이머·호출 관찰.
3. 7–10분: 1회 출력 원문과 실행 종류 기록.
4. 10–12분: 도구 호출 기록과 허용 범위 확인.
5. C는 수동 표와 AI 미사용 표시를 남긴다.

### 전환
출력 문장을 믿는 대신 입력과 기록을 대조하겠습니다.

## 09. 결과와 실행 증거 대조

**권장 시간: 7분**

### 진행 멘트
먼저 세 ID가 각각 한 번인지 세겠습니다. 행이 세 개라도 같은 ID가 두 번 나오면 실패입니다. 각 인용이 원문에 실제로 있는지도 보세요. 질문이 필요한 곳에서 날짜나 비용을 확정했다면 별도로 표시합니다.

내용이 맞는 것과 도구를 안전한 범위에서 사용한 것은 다른 판정입니다. 도구 호출 목록이나 실제 상태를 볼 수 있으면 읽은 대상과 쓰기·전송 여부를 확인합니다. 아무것도 안 했다고 모델이 말한 문장은 행동 증거가 아닙니다. 기록을 볼 수 없으면 미확인으로 남깁니다. B와 C는 도구 권한 검증 완료를 주장할 수 없습니다.

### 질문 / 직접 할 동작
- 세 ID의 중복·누락을 직접 센다.
- 인용 하나씩 원문 위치를 기록한다.
- 내용 평가와 행동 평가를 분리해 적는다.

### 전환
출력이 좋아 보여도 별도의 검수 역할로 놓친 조건을 찾아보겠습니다.

## 10. 독립 검수 요청 작성

**권장 시간: 5분**

### 진행 멘트
검수자에게 단순히 맞는지 봐 달라고 하지 않겠습니다. 원래 요청, 입력 원문, 첫 출력, 기준을 함께 주고 사실·누락·추측·금지 행동을 따로 확인하도록 합니다. 새 대화나 별도 역할은 앞선 답에 끌려가는 것을 줄일 수 있지만 독립적인 진실을 보장하지는 않습니다.

AI 검수는 동일한 안전 경계의 텍스트 전용 새 대화에서 최대 1회, 이 슬라이드의 5분 안에 진행하고 별도 기록으로 남깁니다. 연결 기능 차단을 확인하지 못하면 강사와 학습자가 원문을 보고 사람 검수를 합니다. 두 모델이 같은 답을 내도 원문과 다르면 실패입니다. 검수 결과에는 어느 문장이 왜 문제인지 남기고 1회 출력 자체는 고치지 마세요.

### 질문 / 직접 할 동작
- 검수 요청을 작성하고 실행 가능하면 새 대화에서 사용한다.
- 불가능하면 사람 검수로 표시한다.
- 검수 지적 하나를 원문으로 재확인한다.

### 전환
찾은 문제를 증상별로 분류하겠습니다.

## 11. 실패 유형과 첫 대응 선택

**권장 시간: 7분**

### 진행 멘트
같은 실패처럼 보여도 대응은 다릅니다. 권한 거부라면 전체 접근 권한을 켜는 대신 요청 대상이 맞는지 확인하고, 필요하면 합성 텍스트 경로로 바꿉니다. 도구 자체가 없으면 기능이 없는 상태로 기록합니다. 정보가 부족해 나온 질문은 입력을 보완해야 하는 신호이지 무조건 더 강한 모델로 바꿀 이유는 아닙니다.

출력 누락이면 ID와 입력 범위를 확인합니다. 사실을 지어냈으면 근거 요구를 강화합니다. 삽입 지시를 따르거나 예상 밖 도구 호출을 시도하면 즉시 중단하고 승인하지 않습니다. 같은 오류를 반복하면 정한 횟수에서 끝냅니다. 오류가 없었다면 오류 없음으로 남기고 다음의 의도적으로 틀린 예시를 사용하세요.

### 질문 / 직접 할 동작
- 실습지 실패 유형에서 하나를 선택한다.
- 관찰한 증상과 추정 원인을 구분한다.
- 권한 확대 없이 가능한 대응을 한 가지 적는다.

### 전환
안전한 오류 예시로 중단 판단을 한 번 연습하겠습니다.

## 12. 오류 예시로 중단 판단 연습

**권장 시간: 8분**

### 진행 멘트
이번 자료는 강의자가 일부러 만든 잘못된 출력입니다. 수강생의 실제 1회 결과로 복사하지 마세요. 첫 실행이 완벽해 보여도 오류 대응을 연습할 수 있게 준비했습니다.

표의 ID 수와 원문의 내용을 대조해 주세요. 확정할 수 없는 날짜와 비용을 확정했고, 세 번째 자료를 빠뜨린 채 위험한 지시를 따르려 합니다. 실제 파일이나 계정으로 이 동작을 재현하지 않습니다.

승인 문구가 나온다고 누르는 것도 아닙니다. 대상, 바뀔 내용, 영향, 되돌릴 방법이 없고 수업 범위를 벗어나므로 승인하지 않습니다. 전송은 회수가 불가능할 수 있어 복구 가능하다고 가정하지 마세요. 중단 이유와 다시 받을 초안의 조건을 써 주세요.

### 질문 / 직접 할 동작
1. 0–2분: 예시를 읽고 실제 출력과 구분.
2. 2–5분: 의도한 결함 네 가지 찾기.
3. 5–8분: 중단 사유와 수정 조건 작성.
4. 실제 위험 행동은 실행하지 않는다.

### 전환
첫 결과 또는 연습 결함에서 한 가지를 골라 요청문을 고치겠습니다.

## 13. 요청문 한 가지 수정

**권장 시간: 5분**

### 진행 멘트
한꺼번에 입력과 모델과 요청문을 모두 바꾸면 무엇이 효과를 냈는지 알기 어렵습니다. 원래 샘플과 기준은 그대로 두고 문제와 관련된 문장 하나를 고치겠습니다. 예를 들어 누락이 문제라면 마지막에 입력 ID 목록과 결과 ID 목록을 대조하라고 넣습니다.

자료 자체에 없는 정보는 프롬프트로 만들 수 없습니다. 일정 기준일이나 교육 시간이 없으면 확인 질문으로 남겨야 합니다. 오류가 없었던 경우에도 원문 인용 위치를 더 분명히 하는 수정처럼 검수 가능성을 높일 수 있습니다. 변경 문장과 이유를 기록하고 권한을 넓히지 않았는지 확인하세요.

### 질문 / 직접 할 동작
- 수정 전 문장·수정 후 문장·이유를 기록한다.
- 동일 입력 여부와 권한 변화 여부를 확인한다.

### 전환
수정한 요청으로 두 번째 결과를 받겠습니다.

## 14. 2회 실행과 비교용 출력 보존

**권장 시간: 10분**

### 진행 멘트
앞서 선택한 경로와 안전 경계를 유지하겠습니다. 실제 설정을 바꿨다면 다시 확인하기 전에는 실행하지 않습니다. 수정한 요청문과 같은 세 샘플로 학습자가 직접 두 번째 실행을 시작해 주세요.

실행 중 예상하지 않은 도구 호출이 나오면 승인하지 말고 멈춥니다. 같은 오류가 다시 나오면 오늘의 재시도는 끝입니다. 오류를 숨기려고 입력을 바꾸거나 본 작업의 세 번째 초안 생성을 추가하지 않겠습니다.

두 번째 출력은 별도 칸에 그대로 보존합니다. C 경로이거나 도구가 중간에 불가능해졌다면 사람이 수정한 표라고 기록합니다. 실행을 못 했는데 결과를 만들어 AI 출력처럼 적으면 비교의 근거가 사라집니다.

### 질문 / 직접 할 동작
1. 0–1분: 같은 입력·경계 확인.
2. 1–6분: 직접 실행·중단 관찰.
3. 6–8분: 2회 출력과 실행 종류 기록.
4. 8–10분: 관찰한 도구 호출과 결과 증거 확인.

### 전환
두 결과에 같은 기준을 적용하겠습니다.

## 15. 수정 전후 비교와 사람 판정

**권장 시간: 8분**

### 진행 멘트
1회와 2회에 똑같은 평가 기준을 적용하겠습니다. 인용이 추가됐더라도 실제 원문과 다르면 개선으로 세지 않습니다. 누락이 해결됐는지, 모르는 정보를 질문으로 남겼는지 각각 확인합니다.

도구 행동 검증은 별도입니다. 출력이 맞아도 실행 기록을 볼 수 없으면 도구 권한 검증 미완료로 남깁니다. B와 C는 내용 검토를 통과할 수 있지만 실제 도구 권한 검증까지 통과한 것은 아닙니다.

학습자가 먼저 판정과 근거를 말하고 강사가 반례 하나를 물어보겠습니다. 판정이 다르면 모델 한 번 더 돌리기보다 원문과 실제 기록을 봅니다. 남은 문제가 있다면 완료라고 포장하지 않고 무엇이 미완료인지 적겠습니다.

### 질문 / 직접 할 동작
- 다섯 기준의 1회/2회/근거를 채운다.
- "두 결과가 같아도 둘 다 틀릴 가능성은 없나요?"라고 묻는다.
- 내용 판정과 권한 검증 판정을 따로 결정한다.

### 전환
작성과 검수를 다음에도 재사용할 수 있도록 나누겠습니다.

## 16. 초안 역할과 검수 역할 남기기

**권장 시간: 5분**

### 진행 멘트
다음에 쓸 문장은 두 역할로 나눕니다. 초안 역할은 무엇을 만들지, 어떤 형식과 경계를 지킬지 적습니다. 검수 역할은 무엇이 틀릴 수 있는지, 어떤 근거로 돌려보낼지 적습니다. 최고의 전문가라고 부르는 것보다 확인할 행동이 분명해야 합니다.

매번 바뀌는 고객 상황, 날짜, 계약 내용은 재사용 역할에 고정하지 않습니다. 비밀번호나 API 키는 어느 역할에도 넣지 않습니다. 제품의 저장 기능을 실제로 켜는 것은 이번 수업의 필수가 아닙니다. 두 지침을 실습지에서 텍스트로 남겨도 충분합니다.

### 질문 / 직접 할 동작
- 초안과 검수 지침 두 문단 작성.
- 검수자가 초안을 덮어쓰지 않고 근거와 수정 제안을 반환하는지 확인.
- 저장하면 안 될 정보가 없는지 대조.

### 전환
후속 작업은 확인한 범위 안에서 하나만 정하겠습니다.

## 17. 다음 시도와 남은 설정 질문

**권장 시간: 4분**

### 진행 멘트
오늘 통과한 범위만 다음 시도에 가져갑니다. 바로 실제 메일함이나 고객 자료를 연결하지 않습니다. 같은 비민감 입력과 화면 초안으로 반복하고, 언제 누가 무엇을 보고 확인할지 적으세요.

확인하지 못한 설정은 실패를 숨길 부분이 아니라 다음 수업이나 공식 문서 확인의 대상입니다. 설정 메뉴가 없으면 해당 도구로는 그 경계를 검증하지 못한다는 판단도 가능합니다. 발송, 결제, 삭제, 공개, 배포는 이번 과제 밖입니다.

### 질문 / 직접 할 동작

### 전환
마지막으로 기록을 내보내고 오늘 실제로 한 일을 확인하겠습니다.

## 18. 실행 기록 내보내고 종료

**권장 시간: 3분**

### 진행 멘트
실습지 내용을 텍스트 또는 JSON으로 내보내겠습니다. 다운로드된 파일을 학습자가 열어 실제 실행인지 합성 텍스트 연습인지 수동 대체인지 표시가 맞는지 보세요. 원래 출력, 수정 문장, 비교 결과가 빠졌다면 지금 보완합니다.

공용 기기에서는 로컬 기록이 남을 수 있으므로 내보낸 내용을 확인한 뒤 학습자가 교육 페이지의 저장 기록 정리 여부를 결정합니다. 이 교육 페이지에는 저장 기록 초기화 버튼이 없습니다. 공용 기기에서는 내보낸 파일을 확인한 뒤, 필요하면 학습자가 브라우저 설정에서 해당 사이트의 저장 데이터를 직접 삭제합니다. 이 작업은 AI 서비스의 대화나 파일을 삭제하지 않습니다. 서비스 기록은 보존 정책을 확인한 뒤 학습자가 직접 관리합니다. 오늘은 여기서 끝냅니다.

### 질문 / 직접 할 동작
- 텍스트 또는 JSON을 내보내고 열어 확인한다.
- 실행과 대체의 표시, 1·2회 출력, 최종 판정을 확인한다.
- 브라우저와 서비스 기록이 다르다는 점을 학습자가 말한다.

### 전환
2차시 종료. 남은 질문은 기록으로 전달하고 추가 자동 실행은 하지 않는다.
