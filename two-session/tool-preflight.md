# 2차시 수업 전 도구 준비 점검

제품은 수강생이 사용할 도구로 정합니다. 새 서비스 설치·유료 구독·MCP 연결을 수업 완료의 필수 조건으로 만들지 않습니다. 아래 항목은 강사가 수업 전에 확인할 내용입니다.

## 경로 A · 실제 도구 권한을 확인할 수 있는 환경

1. 실제 고객 자료가 없는 샘플 작업 폴더를 준비합니다. 원본 참고 파일과 결과용 빈 폴더를 분리합니다.
2. 제품의 현재 설정 화면 또는 설정 조회 기능을 열어 작업 위치와 접근 범위를 확인합니다. 지시문에 적힌 내용이 아니라 실제 설정 값을 기록합니다.
3. 파일 읽기, 쓰기, 명령 실행, 외부 네트워크, 연결된 앱·MCP 권한을 각각 확인합니다. 한 설정이 모든 종류의 도구를 통제한다고 가정하지 않습니다.
4. 이 수업에서는 발송·결제·삭제·공개 도구를 사용하지 않습니다. 실제 계정 변경이 필요하면 수강생이 내용을 보고 직접 설정합니다. 자격증명을 강사에게 전달하거나 공유 화면에 노출하지 않습니다.
5. 실행 기록을 어디에서 볼 수 있는지 확인합니다. 승인·거부·오류 기록을 볼 수 없다면 그 항목은 검증 미완료로 남깁니다.
6. 입력 샘플 3개를 처리한 뒤 결과 표와 원문을 비교합니다. 실제 파일 저장을 추가하는 경우 새 초안 파일 하나만 대상으로 하고 생성된 파일을 다시 엽니다.

## 경로 B · 일반 채팅창만 사용할 수 있는 환경

- 가상 자료 3개의 텍스트만 넣고 분류·초안·근거·추가 질문을 받아 봅니다.
- 연결 앱과 실제 자료를 새로 붙이지 않습니다. 로그인이나 API 키 입력 때문에 실습을 멈추지 않습니다.
- 이 경로에서 확인하는 것은 요청문과 출력 품질입니다. 파일·네트워크 샌드박스나 도구 실행 권한을 검증한 것이 아닙니다.
- 실습지에는 “대체 연습 / 도구 권한 검증 미완료”라고 적습니다.
- AI 서비스 자체가 이용 불가하면 강사 작성 오류 예시와 원문을 비교하는 연습으로 전환합니다. 실제 AI 실행은 미완료로 기록하고 후속 과제로 둡니다.
