## 브라우저
- HTML 8개 정상 응답·내부 링크 누락 없음·JS 오류 없음.
- 데스크톱 1440×1000: 46장 전체 순서·텍스트 요소 영역 검사, 영역 밖 텍스트 없음.
- 모바일 390×844: 46장 전체 문서 가로 넘침 없음. 워크시트 주요 화면 시각 확인.
- 워크시트 양쪽: 입력→새로고침 보존, TXT/JSON 다운로드, JSON 재가져오기 확인.
- 1차시 JSON→2차시 인계, 잘못된 JSON 거절·기존 값 유지 확인.
- 목표 저장·설계 문장·슬라이더·퀴즈·체크 저장·전체 보기·클립보드 복사 실제 동작 확인.
- 파일 주소(file://)에서 1차시 워크시트 입력·새로고침 보존 확인. 브라우저 정책에 따른 제한 가능성은 README에 명시.
