# AI 에이전트 활용 기초 · 1차시·2차시 개정판

개인 1:1 수업. 연속 4시간이 아니라 **서로 다른 두 차시, 각각 120분**입니다. 질문·실습·전환 시간을 포함합니다. 별도 추가 실습을 붙이지 않으며 짧은 휴식이 필요하면 가이드의 조정 규칙에 따라 해당 블록 안에서 조정합니다.

## 먼저 열기

ZIP을 모두 푼 뒤 `index.html`을 Chrome 또는 Edge에서 엽니다. 파일 열기에서도 슬라이드·워크시트를 사용할 수 있습니다. 브라우저가 파일 주소에서 로컬 저장을 제한하면 JSON을 내려받거나 아래 로컬 서버를 이용합니다.

Python이 설치되어 있다면 압축을 푼 폴더에서:

```sh
python -m http.server 4390 --bind 127.0.0.1
```

그 기기의 브라우저에서 `http://127.0.0.1:4390/` 열기. 종료는 실행한 터미널에서 Ctrl+C. 외부 공개·계정 연결·AI 실행을 하지 않는 임시 로컬 서버입니다.

## 수업에서 지킬 구분

- **1차시:** 설계만 작성. 워크시트 체크나 설정 문장 생성이 실제 도구 권한을 바꾸지 않습니다.
- **2차시 A:** 실제 권한을 확인할 수 있는 도구로 진행.
- **2차시 B:** 일반 대화형 AI에 가상 자료를 붙여 텍스트 연습. 샌드박스 설정을 완료했다고 기록하지 않음.
- **2차시 C:** AI를 사용할 수 없으면 원문과 의도적 오류 예시로 수동 연습. 실제 실행 성공으로 기록하지 않음.
- 본 작업 초안 생성은 두 번. 선택적 검수는 텍스트만, 최대 한 번·5분이며 해당 검수 블록 안에서 진행합니다.
- 이메일 발송·실제 고객 자료·결제·운영 계정·비밀번호·API 키를 실습에 사용하지 않습니다.
- 이 교육 페이지는 기록 도구이며 AI 서비스에 연결되지 않습니다. 웹폰트 등 외부 자원 로딩은 있을 수 있습니다.

## 기록·기기 이동·인쇄

1. 텍스트 입력 시 이 브라우저의 로컬 저장소에 저장합니다. 자동 기기 동기화는 없습니다.
2. 1차시 종료 때 텍스트 또는 JSON으로 내보내고 실제 파일을 열어 확인합니다.
3. 다음 기기에서는 JSON을 가져옵니다. 1차시 JSON을 2차시 워크시트에 가져오면 인계 영역으로 들어갑니다. 텍스트는 수동 붙여넣기입니다.
4. PDF는 수업용 슬라이드와 인쇄용 빈 워크시트입니다. PDF 자체에 입력하는 전자 양식은 아닙니다. 브라우저에서 입력한 긴 출력 원문은 TXT/JSON으로 보관하세요. 입력칸의 인쇄 높이는 제한됩니다.
5. 공용 기기에서는 내보낸 자료 확인 후 학습자가 브라우저의 해당 사이트 저장 데이터를 정리할지 결정합니다. 교육 페이지에 초기화 버튼은 없으며 AI 서비스 대화·파일 삭제와도 별개입니다.

슬라이드는 이전·다음, 방향키, 전체 보기, 숫자 해시 주소(`#17`)로 이동합니다. 입력칸에서는 방향키로 슬라이드를 넘기지 않습니다.

## 수정·재생성

`curriculum.json`이 슬라이드 내용·시간·강의 스크립트의 기준 파일입니다. 외부 패키지 없이 Python 표준 라이브러리로 HTML과 스크립트를 다시 만들 수 있습니다.

```sh
python build.py
python -m unittest discover -s tests -v
```

HTML 재생성은 기존 PDF를 갱신하지 않습니다. 내용을 바꾼 뒤 브라우저 인쇄/PDF로 다시 출력하고 페이지 수·내용 잘림을 확인하세요. CSS·JS는 별도 파일입니다. 슬라이드 1차시의 원본 시각 양식은 `legacy-deck.css`에 보존했습니다.
