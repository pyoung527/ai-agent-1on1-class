# AI 에이전트 활용 기초

개인 대상 2시간 1:1 실습 수업 자료입니다. AI 에이전트의 개념을 짧게 설명한 뒤, 수강생이 자신의 업무를 골라 작업 범위와 확인 방법을 직접 정하도록 구성했습니다.

## 실행

```bash
cd /home/young-park/ai-agent-1on1-class
./start.sh
```

브라우저에서 다음 주소를 엽니다.

- 수업 슬라이드: http://127.0.0.1:4390/
- 실습 워크시트: http://127.0.0.1:4390/worksheet.html
- 읽기 전용 미니 실습: http://127.0.0.1:4390/lab.html
- 강사용 가이드: http://127.0.0.1:4390/facilitator-guide.html

`index.html`을 직접 열어도 슬라이드는 동작합니다. 저장이 필요한 워크시트는 로컬 서버 실행을 권장합니다.

## 슬라이드 조작

- `→`, `Space`, `PageDown`: 다음 슬라이드
- `←`, `PageUp`: 이전 슬라이드
- `Home` / `End`: 처음 / 마지막
- `O`: 전체 슬라이드 보기
- `F`: 전체화면
- 화면 하단 진행 막대를 클릭해 이동할 수 있습니다.

## 2시간 기본 과정

| 구간 | 시간 | 내용 |
|---|---:|---|
| 시작·목표 | 10분 | AI에게 맡겨보고 싶은 일 정하기 |
| 에이전트 이해 | 25분 | 챗봇·정해진 자동화·에이전트의 차이 |
| 도구·정보·MCP | 20분 | 도구 권한, 현재 정보와 저장 정보, MCP |
| 작업 범위 | 25분 | 파일·사이트·명령·비밀번호·비용 범위 |
| 보안·확인 | 20분 | 문서 속 악성 지시, 과도한 권한, 실행 전 확인 |
| 미니 실습 | 15분 | 개인 업무를 구체적인 작업 지시문으로 작성 |
| 정리·질의 | 5분 | 체크리스트와 다음 단계 |

## 파일 구성

- `index.html`: 수강생에게 보여주는 16:9 수업 슬라이드 28장
- `styles.css`: 화면·인쇄·반응형 디자인
- `app.js`: 슬라이드 이동, 퀴즈, 실습 인터랙션
- `worksheet.html`: 수강생이 작성하는 AI 에이전트 작업 설계표
- `worksheet.js`: 워크시트 로컬 저장 및 JSON 내보내기
- `lab.html`: 가상 문의 3건을 분류하고 답장 초안을 만드는 읽기 전용 실습
- `lab-samples/`: 안전한 가상 문의 파일과 성공 기준
- `facilitator-guide.html`: 강사가 수업 중 참고하는 진행 메모와 질문
- `research/sources.md`: 공식 출처와 수업 반영 근거
- `exports/`: 화면용 슬라이드 PDF, 강사 참고용 가이드 PDF, 수강생 배포용 빈 워크시트 PDF
- `tests/smoke.test.js`: 핵심 구조와 참조 파일 검사

## 개인정보

워크시트 내용은 브라우저의 로컬 저장소에만 저장되며 외부 서버로 전송되지 않습니다. 실제 비밀번호, API 키, 주민등록번호, 금융정보는 실습 자료에 입력하지 마세요.
