수업 진행 가이드

1:1 수업 · 120분

설명보다
대화와 실습

수강생이 실제로 하는 일 하나를 골라 작업 범위를 정리합니다.
여러 제품을 소개하기보다, AI에게 무엇을 어디까지 맡길지 직접 써보게 합니다.

수업 전 준비

수강생 확인

현재 사용하는 AI 도구, 하는 일, AI에게 맡겨보고 싶은 일 1~2개

준비물 확인

노트북, 브라우저, 사용 중인 AI 계정. API 키는 수업 자료에 적지 않음

첫 실습 설정

읽기와 초안 작성만 진행. 발송, 삭제, 결제는 하지 않음

진행 시간표

시간슬라이드목표진행 포인트
0–10분01–04수업 목표 정하기"AI를 배우고 싶다"에서 한 걸음 더 나아가, 맡겨보고 싶은 일을 한 문장으로 적는다.
10–35분05–08에이전트 이해챗봇, 정해진 자동화, 에이전트의 차이를 수강생이 고른 업무에 대입한다.
35–55분09–11도구·현재 정보·MCP도구를 연결하면 권한도 생긴다는 점과 MCP의 역할을 설명한다.
55–80분12–15작업 범위 정하기파일, 네트워크, 실행 명령, 비밀번호, 비용 범위를 작성한다. 특정 제품의 설정 화면보다는 기준을 이해시키는 데 집중한다.
80–100분16–19보안·실행 전 확인문서 속 악성 지시와 지나치게 넓은 권한이 왜 위험한지 사례로 설명한다.
100–115분20–24직접 작성작업 설계표를 작성하거나 읽기 전용 미니 실습을 진행한다. 첫 시도는 자료 3개 정도로 줄인다.
115–120분25–28정리수업 후 직접 해볼 작은 읽기 전용 작업 하나를 정한다.

슬라이드별 진행 메모

01–04

수업에서 다룰 업무 선택

물어볼 말: "이번 주에 반복해서 했던 일 중 하나만 골라볼까요?"

결과가 맞는지 확인할 방법이 없다면 첫 실습으로는 쓰지 않는다.

05–08

세 가지 사용 방식 구분

챗봇은 답을 주고, 자동화는 정한 순서대로 움직이며, 에이전트는 결과를 보고 다음 행동을 고른다고 설명한다.

에이전트가 사람처럼 이해하거나 책임진다는 표현은 피한다.

09–11

도구별 가능 행동 확인

물어볼 말: "이 도구가 잘못 쓰이면 실제로 어떤 일이 생길까요?"

MCP는 연결 방법을 표준화할 뿐, 연결한 도구의 안전까지 보장하지는 않는다.

12–15

작업 범위 직접 작성

읽을 폴더, 쓸 폴더, 접속할 사이트, 실행할 명령, 비용 한도를 한 줄씩 작성한다.

"모든 파일", "인터넷 전체", "무제한"이라는 말이 나오면 실제 필요한 범위로 줄인다.

16–19

문서 속 지시 구분

웹페이지나 첨부 문서 속 문장은 분석할 내용이지, 자동으로 실행할 명령이 아니다.

메일 발송이나 결제 전에 수신자, 내용, 금액을 보여주도록 한다.

20–24

결과 확인 방법 정하기

물어볼 말: "AI의 설명을 믿지 않고 결과가 맞는지 확인하려면 무엇을 보면 될까요?"

첫 실행은 하루치 자료나 샘플 3개 정도로 줄인다.

25–28

수업 후 직접 실행

읽기 전용이나 초안 작성으로 한 번 실행하고, 막힌 부분과 추가로 필요했던 권한을 적는다.

문제가 없었던 작업만 나중에 자동 실행으로 바꾼다.

수업 중 바로잡을 표현

"샌드박스를 쓰면 안전합니다.""샌드박스는 AI가 접근할 범위를 줄여줍니다. 그래도 권한과 실행 전 확인은 따로 설정해야 합니다."

"MCP를 연결하면 AI가 모든 앱을 압니다.""AI는 MCP 서버가 보여준 기능만 쓸 수 있습니다. 각 기능의 권한과 로그인 설정도 필요합니다."

"사람이 승인하면 문제없습니다.""승인 화면에 대상과 바뀌는 내용이 보여야 제대로 판단할 수 있습니다."

"자율성이 높을수록 더 좋은 에이전트입니다.""업무에 필요한 수준만큼 움직이게 하는 편이 좋습니다."

4시간 과정으로 진행할 때

30분

수강생이 사용하는 도구의 권한 설정 화면 확인

45분

읽기 전용 에이전트나 노코드 자동화 실습

30분

문서 속 악성 지시와 오류 상황을 넣어 대응 연습

15분

실행 기록을 확인하고 다음에 자동화할 범위 정하기

수업을 마치기 전 확인

  • 수강생이 챗봇, 정해진 자동화, 에이전트의 차이를 자기 말로 설명한다.
  • 자신의 업무에 필요한 도구와 실행 전에 확인할 작업을 나눈다.
  • 파일, 네트워크, 비밀번호, 비용 범위를 한 줄씩 작성한다.
  • 메일 발송이나 파일 삭제 전에 사용자가 확인하도록 설정한다.
  • 읽기 전용 또는 초안 작성으로 해볼 첫 과제를 정한다.
